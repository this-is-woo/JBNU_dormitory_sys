# 데이터

## jbnu_distance_2026.csv — 거리점수 표 (주소지 드롭다운의 원본)

전북대학교 생활관 「2026학년도 선발기준 거리 데이터」('26.1.1 기준)를 옮겨 적은 표입니다. (251개 시/군/구)
<https://likehome.jbnu.ac.kr>

| 열 | 설명 |
| --- | --- |
| `no` | 공지 표의 번호 |
| `sido_code`, `sido` | 주소 대분류와 코드 (행정표준코드 앞 2자리) |
| `sigungu_code`, `sigungu` | 시·군·구와 코드 (행정표준코드 앞 5자리). 표에만 있는 옛 지역명(인천 남구, 광주·전남 시군구 등)은 옛 코드 |
| `km` | 생활관 관리동 → 시·군·구청 거리 |
| `score` | 가산 환산점수(거리점수) |

**거리 기준**: [2026.1.1. 기준] PC 카카오맵 → 길찾기 → 거리우선(실시간 정보 미포함),
출발지 전북대학교 생활관 관리동, 도착지 학생 주소의 시·군·구청.

홈의 주소지 드롭다운은 **이 표에 있는 시/도 → 시/군/구만** 보여 줍니다. (읍/면/동 단계 없음)
표의 251개 행은 모두 아래 규칙과 정확히 일치하며, `scripts/build_regions.py` 가 생성할 때마다 다시 검사합니다.

```
거리점수 = min(10, 5 + 0.25 × floor(km ÷ 20))      # 20km마다 0.25점, 5 ~ 10점
```

- 도서지역(제주·울릉 등)과 외국 학생은 전원 400km 이상(10점)으로 간주됩니다.
- 새 학년도 표가 공지되면 이 CSV 를 교체하고 스크립트를 다시 실행하세요.

## 다시 생성하기

```bash
python scripts/build_regions.py
```

`frontend/src/data/regions.json` 과 `backend/app/data/distance_scores.json` 이 함께 바뀝니다.
