## jbnu_distance_2025.csv — 거리점수 표

전북대학교 생활관 FAQ 「[선발] 2025학년도 원거리 선발기준 거리 데이터」('25.1.1 기준, 이미지 10장)를 옮겨 적은 표입니다.
<https://likehome.jbnu.ac.kr/home/main/inner.php?sMenu=D4000&mode=view&no=174>

| 열 | 설명 |
| --- | --- |
| `sido`, `sigungu` | 공지 표의 주소 대분류 / 시·군·구 (세종은 시·군·구가 비어 있음) |
| `km` | 생활관 관리동 → 시·군·구청 자동차 최단거리 (카카오맵) |
| `score` | 가산 환산점수(거리점수) |

표의 251개 행은 모두 아래 규칙과 정확히 일치합니다. `scripts/build_regions.py` 가 생성할 때마다 이 규칙으로 다시 검사합니다.

```
거리점수 = min(10, 5 + 0.25 × floor(km ÷ 20))      # 20km마다 0.25점, 5 ~ 10점
```

- 제주·울릉처럼 배·비행기로만 가는 도서지역은 500km(10점)로 처리됩니다.
- 모집요강상 섬 지역 거주자는 증빙서류를 내면 최고점(10점)을 받을 수 있지만, 이 서비스는 시·군·구청 기준 점수만 계산합니다.
- 새 학년도 표가 공지되면 이 CSV 를 교체하고 스크립트를 다시 실행하세요.

## 행정구역 (시/도 → 시/군/구 → 읍/면/동)

행정표준코드관리시스템의 「법정동코드 전체자료」에서 폐지되지 않은 코드만 추려 만듭니다.
주소에 적히는 이름(법정동)을 쓰기 때문에 JUMP/주민등록 주소의 읍·면·동과 그대로 대응됩니다. 리(里) 단위는 제외합니다.

2025 거리표 이후 바뀐 행정구역은 다음과 같이 연결합니다. (`scripts/build_regions.py` 의 `SIDO_LOOKUP`, `ESTIMATED`)

| 현재 행정구역 | 적용한 거리표 값 |
| --- | --- |
| 전남광주통합특별시 (2026.7.1 통합) | 옛 광주광역시·전라남도 시·군·구 값 그대로 |
| 인천 제물포구·영종구 (2026.7.1 신설) | 옛 인천 중구 값 **(추정)** |
| 인천 서해구·검단구 (2026.7.1 신설) | 옛 인천 서구 값 **(추정)** |
| 부천시·화성시의 일반구 | 거리표의 부천시·화성시 값 (거리표가 구를 나누지 않음) |

추정 값은 화면의 거리점수 옆에 "(추정)"으로 표시됩니다.

## 다시 생성하기

```bash
python scripts/build_regions.py --download          # code.go.kr 에서 최신 자료를 받아 생성
python scripts/build_regions.py --source 파일.zip    # 직접 받은 파일로 생성
```

결과물: `frontend/src/data/regions.json`, `backend/app/data/distance_scores.json`
